# Contributing to JustSaid

Thank you for your interest in contributing to JustSaid! We welcome community support to make this privacy-first tool even better.

### How to contribute:
1. **Open an Issue:** Before writing code, please open an issue to discuss your idea or bug fix. This ensures we aren't duplicating work or heading in a direction that conflicts with the project's vision.
2. **Submit a Pull Request (PR):** Once we've discussed the issue, you can submit a PR. 
3. **Maintainer Review:** All code is subject to review by the maintainer. We prioritize privacy, security, and the "local-first" architecture.

### Code of Conduct
Please be respectful and helpful. We are a community focused on privacy and accessibility.

### Disclaimer
Please note that the maintainer (@c-o-d-e-r-s-a) reserves the right to accept or reject any contribution to ensure the long-term stability and security of the JustSaid codebase.
